# Aqua 기획 v0.6 제안: KAST 구조의 한국 적용

작성일: 2026-10-13 · 상태: 제안. 엔진과 정책 값은 아직 바꾸지 않았다.

## 1. 결론

Aqua는 원래 KAST를 거의 그대로 한국에 옮기는 것을 목표로 했다. 결제 잔액과 Reserve, 카드 페이백, 멤버십 등급까지 같은 구조로 만들고 원화 스테이블코인이 나오면 출시하는 계획이다. 이 문서는 그 방향을 기준으로 현재 PoC와 KAST의 차이를 정리하고 무엇을 그대로 가져오고 무엇을 바꿀지 제안한다.

- **그대로 가져올 것:** 페이백 잠금과 받기 단계, 멤버십 등급 구조, 월 결제액 기준 한도, 결제 잔액과 Reserve를 나누는 계정 구조.
- **한국에 맞게 바꿀 것:** 페이백 요율과 재원, Reserve 보상 방식, 카드 혜택 변경 방식, 세금 자료.
- **가장 큰 위험은 Reserve 보상이다.** 정부 통합안은 스테이블코인 보유에 따른 이자와 적립 혜택을 막는 방향으로 보도됐다. KAST처럼 잔액에 연율을 붙이는 방식은 법이 확정되면 그대로 출시하지 못할 수 있다.

## 3. 그대로 가져올 것

### 페이백 잠금과 받기

KAST 방식: 결제 승인 → 14일 잠금 → 받을 수 있음 → 사용자가 받기 → 다음 결제에 먼저 사용.

현재 PoC는 거래가 확정되면 바로 리워드에 넣고, 이미 쓴 페이백이 환불로 취소되면 다음 혜택에서 상계한다. KAST 방식으로 바꾸면 환불 대부분이 잠금 기간 안에 일어나므로 아직 지급하지 않은 페이백을 취소하면 끝난다. 상계는 받은 뒤 환불된 드문 경우에만 남는다. 사용자는 받기 버튼을 누를 때 혜택을 한 번 더 확인한다.

### 등급 구조와 결제액 기준 한도

한도는 페이백 금액보다 월 결제액으로 보여주는 편이 이해하기 쉽다. `월 1만원까지`보다 `월 100만원 결제까지 1%`가 사용자가 직접 비교할 수 있는 숫자다. 표시만 바꾸고 계산 방식은 그대로 둔다.

| 등급 | 현재 | 제안 표시 |
| --- | --- | --- |
| Basic | 1%, 월 페이백 1만원까지 | 1%, 월 100만원 결제까지 |
| Plus | 1.5%, 월 페이백 3만원까지 | 1.5%, 월 200만원 결제까지 |
| Private | 없음 | Reserve 보상 방식이 정해진 뒤 추가 여부 결정 |

KAST 상위 등급의 회비는 높은 Reserve 보상률과 넓은 페이백 한도로 회수되는 구조다. 한국에서 Reserve 보상이 막히고 국내 결제 수수료까지 낮으면 페이백만으로 높은 회비를 설명하기 어렵다. 그래서 세 번째 등급은 화면과 엔진이 지원할 수 있게 만들되 출시 여부는 4장의 Reserve 결정 뒤로 미룬다.

### 이미 반영한 것

- 결제 잔액과 Reserve를 나누고 Reserve에서 결제 부족분을 보충하는 구조
- 코인 입금을 원화 장부로 바꾸고 원래 코인 수량 반환을 약속하지 않는 구조
- 흑백 위주의 화면과 카드 중심의 홈 ([화면 설계](ux-remake.md))

## 4. 한국에 맞게 바꿀 것

### Reserve 보상

보도된 정부 통합안은 스테이블코인 보유자에 대한 이자 지급을 원칙적으로 금지한다. 할인금이나 적립금처럼 이름이 달라도 발행인의 계산으로 보유와 관련해 주는 혜택을 이자로 본다는 지적이 있다. Aqua는 발행인이 아니지만 발행사가 재원을 대면 이 조항에 걸린다. KAST처럼 플랫폼 자체 재원으로 주는 보상은 국내 법안에 해당 범주가 없어 허용 여부가 정해지지 않았다. 미국 CLARITY법 논의는 보유 이자는 금지하고 실거래 기반 보상은 허용하는 방향으로 보도됐다.

| 안 | 방식 | 법적 위험 | 사용자 가치 |
| --- | --- | --- | --- |
| A. KAST 그대로 | 잔액 × 연율, 매일 지급 | 가장 높음. 법 확정 후 금지될 수 있음 | 가장 큼 |
| B. 잔액 연동 결제 혜택 | 리저브 잔액에 따라 페이백 요율이나 한도를 올림. 결제해야 보상이 생김 | 중간. 잔액에 따라 혜택이 커지므로 보유 관련 혜택으로 볼 여지 있음 | 중간 |
| C. 결제 혜택만 | 리저브는 보관과 결제 보충만. 보상은 멤버십 페이백으로만 | 낮음 | 작음 |

제안: PoC는 A안을 유지해 사용자 반응을 계속 확인하고, 엔진의 보상 계산을 A·B·C 중 하나로 바꿀 수 있게 분리한다. 출시안은 법 확정 뒤 법률 검토를 거쳐 고른다. 결정 전까지 화면과 문서에서 Reserve 보상을 이자나 수익률로 부르지 않는다.

### 페이백 요율과 재원

KAST의 1.5%를 국내 결제에 그대로 쓰기 어렵다. 2025-02-14부터 연매출 3억원 이하 영세 가맹점 우대수수료율은 신용카드 0.40%, 체크카드 0.15%다. 국내 결제의 가맹점 수수료만으로는 1% 이상의 페이백 재원이 나오지 않고, 그마저 카드사와 나눠야 한다.

재원 후보는 멤버십 회비, 해외 결제 환전 차익, 코인 자금화 수수료(PoC 0.5%), 제휴 가맹점 예산이다. 기본 등급의 1%는 마케팅 비용으로 보고 월 한도를 낮게 유지한다. 상위 등급의 추가 페이백은 회비로 충당하는지 계산한 뒤 정한다.

### 혜택 변경 방식

국내 카드사 약관은 부가서비스를 출시 후 3년 이상 축소하지 않고, 수익성 악화로 바꿀 때는 6개월 전부터 고지한다고 안내한다. 페이백을 카드 상품의 부가서비스로 설계하면 KAST처럼 요율과 한도를 자주 바꿀 수 없다. 페이백을 카드 부가서비스가 아닌 Aqua 앱 리워드로 운영할 수 있는지, 체크카드나 선불카드에도 같은 기준이 적용되는지 법률 검토가 필요하다.

### 세금 자료

가상자산 소득 과세는 2027-01-01 시행 예정이다(기본공제 연 250만원). 코인 입금을 원화 장부로 바꾸는 구조는 입금 시점의 매도로 볼 수 있어 사용자에게 처분 기록이 생긴다. 연간 입금·전환 내역 내려받기와 리워드의 과세 여부 안내를 후속 화면으로 둔다.

### 출시 조건

| 조건 | 2026-10 상황 (보도 기준) |
| --- | --- |
| 원화 스테이블 법 | 디지털자산기본법 국회 계류. 여당은 연내 통과 목표, 발행 주체와 감독 체계 이견 남음 |
| 발행 주체 | 금융위 인가 방식 논의. 준비자산 은행 수탁 검토 |
| 카드 파트너 | 2017년 이후 금융과 가상자산을 분리하는 감독 기조. 2026년 완화 논의 중. 카드업계는 스테이블코인 결제·정산 적용을 TF에서 기술 검토하는 단계 |
| Aqua 사업자 요건 | 코인 입금·자금화·보관을 하면 특정금융정보법상 가상자산사업자 신고 대상인지, 결제 잔액이 선불충전금에 해당하는지 확인 필요 |

출시 순서 가설: 법 통과 → 발행사 인가 → 발행사·카드사 제휴 → 원화 스테이블 입금만 받는 제한 출시 → 다른 코인 입금 추가.

## 5. PoC 변경 순서 제안

| 순서 | 변경 | 범위 |
| --- | --- | --- |
| 1 | 페이백 잠금 14일과 받기 단계 | 엔진 상태 추가, 혜택 화면의 받을 수 있는 페이백과 받기 버튼, 영수증 문구, 체험 설정의 시간 이동, 테스트 수정 |
| 2 | 한도를 월 결제액 기준으로 표시 | 화면 문구와 정책 표시. 계산 결과는 그대로 |
| 3 | Reserve 보상 계산 분리 (A·B·C) | 엔진 함수 분리, 체험 설정에서 방식 전환 |
| 4 | 세 번째 등급 | Reserve 결정 뒤 |
| 5 | 연간 거래 내역 | 세금 안내와 내려받기 |

1번은 엔진의 페이백 지급 시점이 바뀌므로 단위 테스트와 브라우저 검사의 기대값을 함께 고쳐야 한다. 2번은 화면 변경만이다.

## 6. 결정이 필요한 것

- 페이백 잠금 기간을 KAST와 같은 14일로 할지
- 세 번째 등급의 도입 여부와 회비
- Reserve 보상의 출시 기본안 (A, B, C)
- 페이백을 카드 부가서비스로 둘지 Aqua 리워드로 둘지
