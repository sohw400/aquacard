# Aqua Card 화면 설계

개편일: 2026-10-13 (2차)

## 정보 구조

카드를 첫 화면으로 두고 주 메뉴를 카드, 자산, 혜택, 전체로 구성한다. 카드 관리와 리저브, 이용 내역은 필요한 화면에서 진입하는 상세 화면이다. 뒤로 가기는 진입했던 탭으로 돌아간다.

| 메뉴 | 주요 작업 | 상세 화면 |
| --- | --- | --- |
| 카드 | 사용 가능 금액 확인, 충전, 카드 신청 또는 결제, 최근 카드 이용 확인 | 카드 관리, 이용 내역 |
| 자산 | 총 보유 자산 확인, 결제 잔액 입출금, 기존 보유 코인 전환과 출금 | 리저브 |
| 혜택 | 리워드 우선 사용, 월 페이백 현황, 미수령 보상 받기, 혜택 내역 | 리저브 |
| 전체 | 카드 관리, 이용 내역, 결제 설정, 한도와 요금, 체험 설정 | 카드 관리, 이용 내역 |

960px 미만 화면은 하단 탭, 960px 이상 화면은 왼쪽 사이드바와 가운데 앱 컬럼을 사용한다. 같은 메뉴를 중복 표시하지 않는다. 상세 화면에서도 시작한 탭의 선택 상태를 유지한다.

## 시각 원칙

1차 개편의 흰 배경과 구분선 구조는 섹션 경계가 흐리고 금액과 버튼의 위계가 약했다. 2차 개편은 국내 금융 앱에서 익숙한 묶음 구조로 바꾼다. 색과 간격은 `src/app.css`의 `:root` 토큰에서 관리한다.

- 연회색 배경(`#f2f4f6`) 위에 반경 22px 흰 카드로 관련 정보를 묶는다. 카드 안의 보조 정보와 계산 내역은 더 옅은 면(`#f7f8fa`)으로 구분한다.
- 금액은 굵게 크게 표시하고 tabular-nums로 정렬한다. 입금과 적립은 파란색 `+`, 차감은 기본 글자색 `−`로 표시한다.
- 강조색은 `#1b64da` 한 가지다. 흰 글자와 대비 5.4:1로 WCAG AA를 충족한다. 보조 버튼은 옅은 파랑(`#e8f2ff`) 바탕에 강조색 글자를 쓴다.
- 글자색은 흰 바탕에서 4.5:1 이상인 단계만 쓴다. `#8b95a1`은 아이콘과 비활성 표시에만 쓴다.
- 목록 행은 40px 원형 아이콘, 제목과 설명, 오른쪽 금액, 화살표 순서로 맞춘다. 카드 결제 내역은 가맹점 첫 글자를 아이콘으로 쓴다.
- 상태는 색 배지로 표시한다. 사용 가능은 초록, 신청·심사 진행은 파랑, 보완 필요와 일시 잠금은 주황, 미승인은 빨강이다.
- 한국어는 `word-break: keep-all`로 어절 단위 줄바꿈을 한다.

## 화면 구성

카드 화면은 체험 안내 배너, 플랜과 상태 배지, 큰 카드, 결제 가능 금액과 충전·결제 버튼, 페이백과 리워드 요약, 최근 카드 이용 순서다. 잔액 구성은 결제 가능 금액 옆의 펼침 버튼으로 결제 잔액, 리워드, 리저브를 보여준다. 보유 코인 평가액이나 미수령 리저브 보상을 사용 가능 금액에 더하지 않는다.

카드 관리의 신청 단계는 3칸 진행 막대와 흰 카드 한 장으로 구성한다. 플랜은 카드 색 미리보기가 있는 선택 타일이다. 체크박스와 라디오는 브라우저 기본 입력 요소를 유지하고 모양만 바꾼다. 심사 중에는 진행 막대가 단계에 따라 채워진다. 발급 후에는 카드 정보와 잠금, 한도와 혜택, 실물카드 배송을 각각 별도 카드로 나눈다. 첫 화면에서 카드 신청을 누르면 본인확인 단계로 바로 이동한다. 기본 3단계 신청과 자동 모의 발급은 유지한다.

자산 화면은 총 보유 자산, 결제 잔액과 충전·출금, 리저브, 보유 코인 순서다. 코인을 누르면 시세와 전환·출금 버튼이 펼쳐진다. 잔액이 없는 코인은 흐리게 표시한다. 출금은 결제 잔액만 사용한다. 신규 입금은 원화로 전환되고 기존 코인은 그대로 보유한다는 차이를 표시한다.

혜택은 사용 가능 리워드와 우선 사용 설정, 이번 달 페이백(확정, 확정 대기, 남은 월 한도, 한도 막대), 리저브에서 받을 보상, 최근 혜택 내역 순서다. 보상은 1원부터 받을 수 있으며 혜택 화면과 리저브에서 같은 동작을 제공한다.

이용 내역은 전체·카드·입출금 세그먼트로 거르고 날짜별로 묶는다. 행마다 상세 설명을 펼칠 수 있고 확정된 결제에는 환불 버튼을 둔다. 전체 환불된 결제 금액에는 취소선을 긋는다.

전체 화면은 체험 프로필, 카드 및 이용 내역, 결제 설정, 카드 요금, 접힌 체험 설정 순서다.

## 시트와 피드백

충전, 결제, 환불, 전환, 영수증은 640px 미만에서 아래에서 올라오는 시트, 그 이상에서 가운데 대화상자로 연다. 제목과 확인 버튼은 고정하고 본문만 스크롤한다. 확인 버튼은 56px 높이로 금액과 동작을 함께 표시한다. 금액 입력은 32px 이상 굵은 숫자에 밑줄 입력란을 쓴다. 결제 체험에는 예시 결제처 3개를 둔다.

움직임은 시트와 대화상자 등장, 토스트 등장, 누를 때 살짝 줄어드는 반응, 영수증 완료 표시만 사용한다. 동작 감소 설정에서는 모두 끈다. 마우스 hover 효과는 hover 가능한 기기에서만 적용해 터치 뒤에 강조가 남지 않게 한다.

## 문구와 글꼴

글꼴은 기기 기본 글꼴을 사용한다. 별도 웹 글꼴과 관련 배포 파일을 제거했다. 금액은 `132,780원`처럼 표시한다. 실제 금융 상태와 사용자가 할 일을 구체적인 한국어로 작성한다.

화면 문구에 이모지, em dash, 장식적인 영문 표제, 홍보성 보안 표현을 쓰지 않는다. 승인된 카드 표면의 브랜드와 3D는 변경하지 않는다.

## 입출금과 영수증

충전 화면에서 자산, 네트워크, 수량, 수수료와 받을 금액을 확인한다. 출금 화면에서는 원화 차감액과 예상 코인 수량을 확인한다. 30초 견적 및 기존 금융 계산을 유지한다. 화면에 모의 입출금임을 표시한다.

영수증은 완료 표시, 결제 금액, 사용한 원금과 리워드, 새 페이백, 결제 후 리워드 잔액을 구분한다. 이전 페이백 상계와 처리 중 다른 잔액 변동을 숨기지 않는다. 영수증이나 입출금 화면이 열리면 토스트 알림을 표시하지 않아 금액을 가리지 않도록 한다.

## 접근성과 검증

주 메뉴, 뒤로 가기, 주요 작업, 스위치는 최소 44px 터치 영역을 둔다. 금액과 텍스트 입력은 16px 이상으로 표시한다. 모달은 초점을 가두며 Escape로 닫을 수 있다.

3D 카드에는 기존 동작 감소 및 터치 대응을 유지한다. 단위 테스트와 화면별 브라우저 검사, 5개 모바일 크기 검사를 실행한다. 실제 iOS와 Android 기기 검증은 별도다.
