# Aqua Card 화면·사용 흐름 개편

작성일: 2026-10-13

## 화면 원칙

결제에 쓸 수 있는 금액과 다음 행동을 먼저 보여준다. 보유 자산 평가액, 출금 가능한 원금, 결제 전용 리워드는 구분한다. 홍보 문구, 영문 슬로건, 반복 배지, 장식용 차트와 보안 주장을 줄인다. 흰색·옅은 회색 바탕, 짙은 텍스트와 하나의 파란 강조색을 사용한다.

| 화면 | 먼저 보여주는 정보 | 추가 정보 접근 |
| --- | --- | --- |
| 홈 | 사용 가능 금액, 충전·결제, 카드 상태 | 리저브 요약·최근 내역 |
| 지갑 | 원화 결제 잔액, 보유 코인 | 코인 선택 후 입금·출금·전환 |
| 카드 | 카드 신청 또는 카드 정보·잠금 | 실물 배송과 체험 도구 |
| 리저브 | 원금, 넣기·빼기, 적립 보상 | 보상 조건·변경 기록 |

주 메뉴는 4개이며 모바일에서는 하단에 배치한다. 이용 내역과 설정은 상단 보조 버튼으로 접근한다. 화면에서 작업을 선택하면 지갑·코인·이동 방향이 정해진 모달을 열어 금액만 입력하게 한다. 코인 전환 수수료와 결제 출처·예상 페이백은 확정 전에 표시한다.

## 카드 신청

1. 샘플 본인확인과 체험 안내를 확인한다.
2. Basic 또는 Plus를 선택한다. 가상카드를 기본 제공하고 실물카드는 추가 옵션으로 둔다.
3. 비용·혜택을 확인하고 신청한다.

신청 후 모의 심사·가상 발급·활성화는 약 2.25초에 자동 진행한다. 내부 상태와 검증 순서는 유지한다. 보완·거절·배송 상태는 접힌 체험 도구로 확인하며, 심사 도구를 열면 자동 진행이 일시 정지된다. 실제 출시에서는 본인확인·카드 대행사 응답에 따라 처리해야 한다.

## 잔액·혜택 설명

홈의 사용 가능 금액은 리워드 우선 사용 및 리저브 자동 사용 설정에 따라 계산한다. 리저브 자동 사용은 결제 잔액 부족분에만 적용하고 사용한 원금은 이후 적립 대상에서 빠진다. 적립 중인 보상과 결제용 리워드 잔액을 구분하며, 리워드는 출금할 수 없다. 원화 스테이블은 발행사 제휴 후 지원 대상으로 표시한다.

연 5% 변동 보상, Basic·Plus 페이백, 수수료·한도·환불·보상 계산은 이번 개편에서 변경하지 않았다. 시간 진행과 보상률 변경은 설정의 접힌 체험 도구로 옮겼다.

## 검증

금융 로직 22개, 브라우저 시나리오 13개, 320–430px 기기 프로필 5개를 검증한다. 프로필 테스트는 Chromium 모사이며 실제 Safari·Android 하드웨어 테스트와 구분한다. 모의 체험과 실제 자금 이동·카드 발급이 없다는 사실은 모든 화면에서 안내한다.
