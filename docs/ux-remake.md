# Aqua Card 화면 설계

개편일: 2026-10-13

## 정보 구조

카드를 첫 화면으로 두고 주 메뉴를 카드, 자산, 혜택, 전체로 구성한다. 카드 관리와 리저브, 이용 내역은 필요한 화면에서 진입하는 상세 화면이다. 뒤로 가기는 진입했던 탭으로 돌아간다.

| 메뉴 | 주요 작업 | 상세 화면 |
| --- | --- | --- |
| 카드 | 사용 가능 금액 확인, 충전, 카드 신청 또는 결제, 최근 카드 이용 확인 | 카드 관리, 이용 내역 |
| 자산 | 결제 잔액 입출금, 기존 보유 코인 전환과 출금 | 리저브 |
| 혜택 | 리워드 우선 사용, 월 페이백 현황, 미수령 보상 받기, 혜택 내역 | 리저브 |
| 전체 | 카드 관리, 이용 내역, 결제 설정, 한도와 요금, 체험 설정 | 카드 관리, 이용 내역 |

데스크톱은 상단 메뉴, 모바일은 하단 메뉴를 사용한다. 같은 메뉴를 중복 표시하지 않는다. 상세 화면에서도 시작한 탭의 선택 상태를 유지한다.

## 화면 구성

흰 배경과 구분선을 기본으로 삼는다. 숫자와 작업 버튼을 중심으로 정렬하고, 중첩된 패널과 장식 배지, 효과를 위한 차트는 사용하지 않는다. 이전에 누적된 전역 스타일은 새 구조에 맞춰 교체했다.

카드 화면은 큰 카드와 결제 가능 금액을 연결한다. 모바일은 카드, 금액, 충전 및 결제, 페이백 및 리워드, 최근 카드 이용 순서다. 데스크톱은 카드와 금액을 나란히 배치한다. 보유 코인 평가액이나 미수령 리저브 보상을 사용 가능 금액에 더하지 않는다.

카드 관리에는 신청 상태, 카드 정보, 잠금, 실물 카드 배송을 둔다. 첫 화면에서 카드 신청을 누르면 본인확인 단계로 바로 이동한다. 기본 3단계 신청과 자동 모의 발급은 유지한다. 주요 버튼은 카드 상태에 따라 카드 신청, 신청 이어하기, 정보 확인, 발급 상태, 잠금 해제, 결제 체험으로 바뀐다.

자산 화면은 결제 잔액, 리저브, 보유 코인을 구분한다. 출금은 결제 잔액만 사용한다. 신규 입금은 원화로 전환되고 기존 코인은 그대로 보유한다는 차이를 표시한다.

혜택은 독립된 화면이다. 사용 가능 리워드, 우선 사용 설정, 확정 페이백, 확정 대기, 남은 월 한도, 미수령 리저브 보상 순서로 보여준다. 보상은 1원부터 받을 수 있으며 혜택 화면과 리저브에서 같은 동작을 제공한다.

## 문구와 글꼴

글꼴은 기기 기본 글꼴을 사용한다. 별도 웹 글꼴과 관련 배포 파일을 제거했다. 금액은 `132,780원`처럼 표시한다. 실제 금융 상태와 사용자가 할 일을 구체적인 한국어로 작성한다.

화면 문구에 이모지, em dash, 장식적인 영문 표제, 홍보성 보안 표현을 쓰지 않는다. 승인된 카드 표면의 브랜드와 3D는 변경하지 않는다.

## 입출금과 영수증

충전 화면에서 자산, 네트워크, 수량, 수수료와 받을 금액을 확인한다. 출금 화면에서는 원화 차감액과 예상 코인 수량을 확인한다. 30초 견적 및 기존 금융 계산을 유지한다. 화면에 모의 입출금임을 표시한다.

영수증은 결제 금액, 사용한 원금과 리워드, 새 페이백, 결제 후 리워드 잔액을 구분한다. 이전 페이백 상계와 처리 중 다른 잔액 변동을 숨기지 않는다. 영수증이나 입출금 화면이 열리면 토스트 알림을 표시하지 않아 금액을 가리지 않도록 한다.

## 접근성과 검증

주 메뉴, 뒤로 가기, 주요 작업, 스위치는 최소 44px 터치 영역을 둔다. 금액 입력은 16px 이상으로 표시한다. 작은 화면에서는 시트의 제목과 확인 버튼을 고정하고 본문만 스크롤한다. 모달은 초점을 가두며 Escape로 닫을 수 있다.

3D 카드에는 기존 동작 감소 및 터치 대응을 유지한다. 그 밖의 화면에 새 등장 애니메이션을 추가하지 않는다. 단위 테스트와 화면별 브라우저 검사, 5개 모바일 크기 검사를 실행한다. 실제 iOS와 Android 기기 검증은 별도다.
