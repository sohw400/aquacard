# 입출금 흐름

작성일: 2026-10-13

Aqua는 원화(법정화폐) 입출금을 지원하지 않는다. 결제 잔액은 **원화 스테이블코인**으로 보관하고, 다른 코인은 받는 대로 원화 스테이블로 바꿔 결제 잔액에 넣는다. KAST처럼 **코인을 보유 자산으로 들고 있지 않는다.** 자산 탭에는 결제 잔액(원화 스테이블)과 리저브만 있고, 코인은 "충전할 수 있는 코인" 안내로만 보인다. 원화 스테이블의 실제 이름·발행사·네트워크는 제휴 후 정하며 PoC는 `KRWS`라는 자리표시자를 쓴다(1 KRWS = 1원).

## 화면 구성

| 경로 | 입력 | 확인 | 처리 결과 |
| --- | --- | --- | --- |
| 충전(입금) | 보내는 곳, 코인, 네트워크 → 받는 주소 확인 → 보낸 수량(체험) | 입금 평가액, 입금 수수료 0원, 결제 잔액에 더할 금액 | 입금 대기 → 네트워크 확인 → 원화 스테이블 전환 → 완료 |
| 결제 잔액에서 출금 | 코인, 네트워크, 받는 사람, 주소, 금액 | 전환 수수료(원화 스테이블은 없음), 네트워크 비용, 예상 수령량, 출금 후 잔액, **이메일 인증** | 검토 → 전송 → 완료 |
| 리저브 넣기·빼기 | 금액 | 출발·도착 잔액, 수수료 0원 | 완료 영수증 |

## 보내는 곳(입금 경로)

KAST처럼 "어디서 보내는지"부터 고르게 해 주소 복사 이후의 할 일을 줄였다.

| 보내는 곳 | 안내 |
| --- | --- |
| 국내 거래소 | 업비트·빗썸·코인원·코빗에서 출금을 열고 코인·네트워크를 고른 뒤 주소를 붙여 넣는 4단계. 100만원 이상은 트래블룰에 따라 받는 곳을 Aqua로 고른다는 안내를 덧붙인다. |
| 해외 거래소 | 트래블룰을 지원하는 거래소에서만 받는다는 안내. |
| 내 지갑 | 메타마스크·팬텀 같은 개인 지갑에서 보내는 3단계. |
| 주소로 받기 | 주소를 복사해 보내는 2단계. |

입금 주소는 `aqua-preview:polygon:krws` 같은 체험용 식별자다. 실제 체인 주소·QR로 보이지 않게 하고, 주소 주변과 최종 확인에서 실제 송금이 불가능함을 안내한다.

## 수수료

| 구분 | Aqua 수수료 |
| --- | --- |
| 입금(충전) | 없음. 원화 스테이블이 아닌 코인도 전환 수수료 없이 바꿔 넣는다. 보내는 곳의 출금 수수료는 그쪽에서 따로 낸다. |
| 결제 잔액 → 원화 스테이블 출금 | 네트워크 비용만 |
| 결제 잔액 → 다른 코인 출금 | 전환 수수료 0.5%(원 단위 올림) + 네트워크 비용 |
| 리저브 넣기·빼기 | 없음 |

네트워크 비용 예시(고정값): Polygon 140원, Ethereum 2,800원(ETH 출금은 2,000원), Bitcoin 1,500원. 예를 들어 결제 잔액에서 USDC를 Polygon으로 10,000원 출금하면 전환 수수료 50원과 네트워크 비용 140원을 빼고 9,810원 상당을 보낸다. 리워드와 리저브는 출금에 쓰지 않는다.

## 인증

- 가입할 때 이메일 인증과 본인확인(휴대폰·신분증·얼굴·고객확인 질문)을 마쳐야 앱을 쓸 수 있다.
- 출금은 요청 전에 가입한 이메일로 받은 6자리 코드를 넣어야 한다. 체험판은 메일을 보내지 않고 코드를 화면에 보여 준다.
- 실제 서비스는 출금 주소 화이트리스트, 기기 인증, 이상 거래 탐지를 더한다.

## 처리 중인 금액

출금 접수 시 총액을 결제 잔액에서 예약한다. 처리 중인 금액은 다른 출금·결제·리저브 이동에 쓸 수 없고, 완료 전까지 총 보유 자산에는 포함한다. 입금 대기와 출금 검토 단계에서는 취소할 수 있고, 전송이 시작되면 취소할 수 없다. 모의 실패는 예약한 원금과 수수료 전액을 돌려준다.

이전 체험에서 코인을 보유한 상태로 저장된 데이터는 불러올 때 고정 시세로 원화 스테이블로 바꿔 결제 잔액에 더하고, 이용 내역에 "보유 코인 자동 전환"을 남긴다.

작업과 단계별 예정 시각은 브라우저에 저장된다. 창을 닫거나 새로고침해도 자산의 입출금 현황과 이용 내역에서 상세를 다시 열 수 있고, 같은 완료 처리를 반복해도 잔액은 다시 바뀌지 않는다.

## 받은 코인은 누가 파는가

KAST는 사용자가 코인을 보내면 그 자산을 KAST에 넘기는 것으로 보고(약관상 소유권 이전), 사용자에게는 USD 기준 장부 잔액을 보여 준다. 실제 시장 매도 시점은 공개하지 않는다. Aqua도 사용자가 보기에는 같은 경험(받는 즉시 원화 스테이블 잔액)을 주되, 실제 전환은 제휴 거래소·OTC가 맡고 Aqua는 결과만 장부에 반영하는 구조를 기본안으로 한다. 자세한 비교는 [KAST 구조의 한국 적용](kast-alignment.md#받은-코인의-전환-kast는-어떻게-하나)에 정리했다.

## 구현 경계

현재는 브라우저 안의 모의 처리다. 단계 전환 간격(약 3초)은 실제 체인 처리 시간이 아니다. 실제 입금 감지·전송·정산, 서버 서명 견적, 수탁·거래 파트너 연동, 여러 기기 사이의 동시성은 연동 전이다. 금융 서버 구조는 [백엔드 설계](funding-architecture.md)를 따른다.
