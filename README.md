# Aqua Card PoC

한국 사용자를 위한 카드 서비스 **Aqua Card**의 인터랙티브 PoC입니다. 코인을 보내면 받는 즉시 원화 스테이블로 바뀌어 결제 잔액이 되고, 카드로 쓰면 페이백을, 리저브에 두면 1초마다 보상을 받습니다. KAST의 구조를 한국 원화 스테이블에 맞춰 옮겼습니다.

React·TypeScript·Vite로 만든 웹 앱이며 모든 자금·카드·본인확인은 브라우저 안의 모의 처리입니다. 실제 입금, 카드 발급, 개인정보 확인, 외부 송금이나 과금은 하지 않습니다.

## 실행

Node.js 22.12 이상이 필요합니다.

```bash
npm ci --no-audit --no-fund
npm run dev
```

개발 서버는 5173번 포트를 씁니다.

## 검증

```bash
npm test
npm run build
```

개발 서버가 떠 있고 Chromium이 있는 환경에서는 브라우저 흐름도 확인합니다.

```bash
npm run test:browser
npm run test:devices
```

Chromium 경로는 `CHROMIUM_PATH`, 서버 주소는 `AQUA_BASE_URL`로 바꿀 수 있습니다(기본 `/usr/bin/chromium`, `http://127.0.0.1:5173`).

2026-10-13 기준 로직 테스트 {UNIT}개, 데스크톱·모바일 브라우저 검사 {BROWSER}개, 320~430px 기기 프로필 5개가 통과했습니다. 기기 프로필은 Chromium에서 화면 크기와 터치를 **모사**한 것이며 실제 iOS Safari·Android 실기기 검증과 다릅니다. 자세한 절차는 [테스트 안내](docs/testing.md)에 있습니다.

## 둘러보기

[Aqua Card 웹 데모](https://sohw400.github.io/aquacard/)는 `main`에 반영된 버전입니다([배포 안내](docs/deployment.md)).

1. **가입**: 이메일 인증 → 비밀번호 → 휴대폰 인증 → 신분증·얼굴 확인 → 고객확인 질문. 가입을 마쳐야 앱을 쓸 수 있고 로그인·비밀번호 찾기를 지원합니다.
2. **충전**: 보내는 곳(국내 거래소·해외 거래소·내 지갑·주소)과 코인(원화 스테이블·USDC·USDT·BTC·ETH), 네트워크를 고르면 받는 주소와 보내는 순서를 안내합니다. 입금 수수료는 없고, 받은 코인은 확인 즉시 원화 스테이블로 바뀌어 결제 잔액이 됩니다. 앱에 코인 보유량은 남지 않습니다.
3. **출금**: 결제 잔액에서 나갑니다. 원화 스테이블은 네트워크 비용만, 다른 코인으로 바꿔 보내면 전환 수수료 0.5%가 붙습니다. 이메일 인증을 거칩니다.
4. **카드**: 본인확인 → 카드 선택(Basic·Plus, 실물카드와 배송지) → 신청 확인. 신청 비용은 결제 잔액에서 내고, 반려되면 돌려받습니다. 발급 후 카드 정보·잠금, 삼성페이·Apple Pay 추가, 플랜 변경과 월 이용료 결제일, 실물카드 비밀번호·활성화, 분실 재발급, 해지를 지원합니다.
5. **리저브와 리워드**: 리저브에 둔 금액의 보상이 1초마다 쌓여 1원 단위로 리워드에 바로 더해집니다(받기 버튼 없음). 리워드는 카드 결제에 먼저 쓰이며 출금할 수 없습니다.
6. **결제**: 리워드 → 결제 잔액 → (켠 경우) 리저브 순서로 씁니다. 결제 방식(매장·온라인·해외), 사용자가 정한 결제 한도, 온라인·해외 결제 차단을 적용하고 확정되면 페이백을 적립합니다.
7. **이용 내역**: 거래 상세(승인번호, 결제 구성, 페이백)와 부분·전액 환불.
8. **전체**: 결제 한도, 온라인·해외 결제, 리워드·리저브 자동 사용, 비밀번호 변경, 알림·광고성 정보 동의, 자주 묻는 질문, 약관, 회원 탈퇴, 체험 설정.

주 메뉴는 홈·자산·혜택·전체입니다. 모바일은 하단 탭, 넓은 화면은 왼쪽 사이드바로 표시하고 기기 설정에 따라 다크 모드로 바뀝니다. 글꼴은 앱에 포함한 Pretendard Variable입니다([글꼴](docs/fonts.md)). 첫 화면의 카드와 리워드 카드의 동전은 three.js로 렌더링한 3D 이미지입니다. 화면 구조는 [UX 개편안](docs/ux-remake.md)을 따릅니다.

상태는 이 브라우저의 localStorage에만 저장됩니다. 실제 이름·휴대폰·신분증·주소를 넣지 마세요. 화면의 `체험용 주소 넣기`, `샘플 정보 채우기`, 예시 주소 검색을 쓰면 됩니다. 비밀번호는 해시만 저장합니다.

## 기본 정책

기준 파일은 [policy.ts](src/lib/policy.ts)입니다.

| 항목 | Basic | Plus |
| --- | --- | --- |
| 월 이용료 | 무료 | 4,900원(결제 잔액에서 매달 같은 날) |
| 카드 페이백 | 1%, 월 1만원까지 | 1.5%, 월 3만원까지 |
| 리저브 보상 | 연 5% 단리·변동형, 1천만원까지 | 동일 |
| 실물카드 | 발급비 9,900원(선택), 재발급 9,900원 | 동일 |
| 입금 | 무료(코인은 받는 즉시 원화 스테이블로 전환) | 동일 |
| 출금 | 네트워크 비용, 다른 코인으로 보내면 전환 수수료 0.5% | 동일 |
| 결제 한도 | 최대 1회 50만원·하루 100만원·한 달 500만원, 사용자가 낮출 수 있음 | 동일 |

원화(법정화폐) 입출금은 지원하지 않습니다. 원화 스테이블의 실제 이름·발행사·네트워크는 제휴 후 정하며 PoC는 `KRWS`라는 자리표시자를 씁니다. 시세는 고정 예시입니다.

KAST는 사용자가 보낸 코인의 소유권을 넘겨받고 USD 장부 잔액을 주는 구조이며, 실제 매도 시점은 공개하지 않습니다. Aqua는 같은 경험을 주되 실제 전환은 제휴 거래소·OTC가 맡는 구조를 권합니다([KAST 구조의 한국 적용](docs/kast-alignment.md), [공식 조사](docs/kast-funding-model.md), [입출금 흐름](docs/funding-flows.md)).
