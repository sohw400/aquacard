# Aqua Card PoC

한국 사용자를 위한 카드 서비스 **Aqua Card**의 인터랙티브 PoC입니다. 코인을 보내면 받는 즉시 원화 스테이블로 바뀌어 잔액이 되고, 카드로 쓰면 페이백을, 리저브에 두면 1초마다 보상을 받습니다. KAST의 구조(받은 코인 자동 매도, 세 멤버십, 회원 간 무료 송금)를 한국 원화 스테이블에 맞춰 옮겼고, 멤버십 요금과 요율은 한국 카드 시장에 맞췄습니다.

React·TypeScript·Vite로 만든 웹 앱이며 모든 자금·카드·본인확인은 브라우저 안의 모의 처리입니다. 실제 입금, 카드 발급, 개인정보 확인, 외부 송금이나 과금은 하지 않습니다.

## 실행

Node.js 22.12 이상이 필요합니다.

```bash
npm ci --no-audit --no-fund
npm run dev
```

개발 서버는 5173번 포트를 씁니다.

## 검증

```bash
npm test
npm run build
```

개발 서버가 떠 있고 Chromium이 있는 환경에서는 브라우저 흐름도 확인합니다.

```bash
npm run test:browser
npm run test:devices
```

Chromium 경로는 `CHROMIUM_PATH`, 서버 주소는 `AQUA_BASE_URL`로 바꿀 수 있습니다(기본 `/usr/bin/chromium`, `http://127.0.0.1:5173`).

2026-10-14 기준 로직 테스트 117개, 데스크톱·모바일 브라우저 검사 54개, 320~430px 기기 프로필 5개가 통과했습니다. 기기 프로필은 Chromium에서 화면 크기와 터치를 **모사**한 것이며 실제 iOS Safari·Android 실기기 검증과 다릅니다. 자세한 절차는 [테스트 안내](docs/testing.md)에 있습니다.

## 둘러보기

[Aqua Card 웹 데모](https://sohw400.github.io/aquacard/)는 `main`에 반영된 버전입니다([배포 안내](docs/deployment.md)). 가입 직후 체험 잔액은 128,500원입니다.

1. **가입**: 이메일 인증 → 비밀번호 → 휴대폰 인증 → 신분증·얼굴 확인 → 본인 계좌 확인(1원 인증, 샘플 계좌) → 고객확인 질문. 가입을 마쳐야 앱을 쓸 수 있고 로그인·비밀번호 찾기를 지원합니다.
2. **홈**: 맨 위에 잔액 하나와 `충전`·`보내기`가 있고, 아래에 내 카드, 실시간 리워드와 리저브, 최근 거래가 이어집니다. 코인은 보유하지 않으므로 코인 목록이나 자산 탭이 없습니다.
3. **충전**: 홈 › 충전에서 보내는 곳(국내 거래소·해외 거래소·내 지갑·주소로 받기), 코인(원화 스테이블·USDC·USDT·BTC·ETH), 네트워크를 고르면 받는 주소와 보내는 순서를 안내합니다. 입금 수수료는 없고, 받은 코인은 확인 즉시 원화 스테이블로 바뀌어 잔액이 됩니다.
4. **보내기**: 홈 › 보내기에서 `Aqua 회원에게`(태그·이름·휴대폰 번호·이메일로 찾아 수수료 없이 바로, 예: @minji.k, 010-0000-0101, minji.kim@aqua.example), `QR 코드 찍기`(체험판은 체험용 QR을 골라 대신함), `지갑 주소로`(네트워크 비용, 원화 스테이블이 아닌 코인은 전환 수수료 0.5%, 이메일 인증) 중 고릅니다.
5. **카드**: 카드 › 카드 만들기에서 본인확인 → 멤버십(스탠다드·프리미엄·프라이빗, 실물카드와 배송지) → 신청 확인. 스탠다드는 실물카드까지 무료라 신청해도 잔액이 128,500원 그대로입니다. 발급 후 카드 정보·잠그기·결제해 보기, 삼성페이·Apple Pay 추가, 실물카드 비밀번호·활성화, 분실 재발급, 해지를 지원합니다.
6. **멤버십**: 카드 › 멤버십에서 프리미엄으로 바꾸면 연회비 100,000원이 잔액에서 바로 나갑니다(128,500원 → 28,500원). 이미 실물카드를 받았다면 메탈 카드(프라이빗은 골드 카드)를 새로 보내고, 받아서 `새 카드 쓰기 시작`을 누를 때까지 지금 카드를 그대로 씁니다. 내리기는 갱신일에 바뀌도록 예약되고, 갱신일에 잔액이 모자라면 스탠다드로 바뀝니다. 카드 탭 아래 체험 도구의 `갱신일로 이동`으로 바로 확인할 수 있습니다.
7. **리저브와 리워드**: 리저브에 둔 금액의 보상이 1초마다 쌓여 1원 단위로 리워드에 바로 더해집니다(받기 버튼 없음). 리워드는 카드 결제에 먼저 쓰이며 출금할 수 없습니다.
8. **결제**: 리워드 → 잔액 → (켠 경우) 리저브 순서로 씁니다. 결제 방식(매장·온라인·해외), 사용자가 정한 결제 한도, 온라인·해외 결제 차단을 적용하고 확정되면 페이백을 적립합니다. 스탠다드에서 `리워드 먼저 쓰기`를 끄고 5,800원을 결제하면 페이백 58원이 쌓입니다.
9. **거래 내역**: 오른쪽 위 시계 아이콘에서 엽니다. 거래 상세(승인번호, 결제 구성, 페이백), 부분·전액 환불, 입출금 처리 내역을 봅니다.
10. **전체**: 프로필, 내 태그와 QR(태그 바꾸기, 휴대폰 번호·이메일로 찾기 허용, 회원에게 받기 체험), 카드(결제 한도, 온라인·해외 결제, 연간 거래 내역), 결제 순서(리워드·리저브 자동 사용), 계정(비밀번호 변경, 알림·광고성 정보 동의, 로그아웃, 회원 탈퇴), 요금, 도움말(자주 묻는 질문, 약관), 체험 설정.

주 메뉴는 홈·카드·혜택·전체이고 리저브, 거래 내역, 연간 거래 내역은 상세 화면입니다. 연간 거래 내역은 연도별 요약과 세금 신고 안내를 보여 주고, 내역을 표 형태로 복사해 엑셀이나 구글 시트에 붙여 넣을 수 있습니다. 모바일은 하단 탭, 넓은 화면은 왼쪽 사이드바로 표시하고 기기 설정에 따라 다크 모드로 바뀝니다. 흰 바탕을 가는 선으로 나누고, 상자처럼 보이는 것은 카드와 어두운 리워드 블록뿐입니다. 앱 문구는 해요체로 씁니다. 글꼴은 앱에 포함한 Pretendard Variable입니다([글꼴](docs/fonts.md)). 첫 화면·홈·카드 소개의 카드(네이비 스탠다드를 앞에, 골드 프라이빗을 뒤에)와 리워드 블록의 동전은 three.js로 렌더링한 3D 이미지입니다. 카드는 실시간으로 렌더링해서, 누르거나 마우스를 올리면 살짝 기울고 빛반사가 따라 움직입니다(동작 감소 설정에서는 정지 이미지). 화면 구조는 [화면 설계](docs/ux-remake.md)를 따릅니다.

상태는 이 브라우저의 localStorage에만 저장됩니다. 실제 이름·휴대폰·신분증·주소를 넣지 마세요. 화면의 `체험용 주소 넣기`, `샘플 정보 채우기`, 예시 주소 검색을 쓰면 됩니다. 비밀번호는 해시만 저장합니다. 이전 체험의 Basic·Plus 데이터는 스탠다드로 불러옵니다.

## 기본 정책

기준 파일은 [policy.ts](src/lib/policy.ts)입니다. 멤버십은 KAST의 세 등급 구조를 따르고 금액은 한국 카드 시장에 맞췄습니다([한국 시장에 맞춘 파라미터](docs/kast-alignment.md#한국-시장에-맞춘-파라미터)).

| 항목 | 스탠다드 | 프리미엄 | 프라이빗 |
| --- | --- | --- | --- |
| 연회비 | 무료 | 100,000원 | 500,000원 |
| 카드 페이백 | 1%, 월 100만원 결제까지(최대 1만원) | 1.5%, 월 200만원 결제까지(최대 3만원) | 2%, 월 500만원 결제까지(최대 10만원) |
| 리저브 보상 | 연 5% 단리·변동형, 1천만원까지 | 연 5.5%(+0.5%p), 3천만원까지 | 연 6%(+1%p), 5천만원까지 |
| 실물카드 | 선택, 무료 | 메탈 카드 포함 | 골드 카드 포함 |
| 재발급 | 무료 | 무료 | 무료 |

연회비는 잔액에서 먼저 내고 1년마다 같은 날 다시 냅니다. 등급을 올리면 새 연회비를 바로 내고 즉시 바뀌며 남은 기간은 일할 계산하거나 돌려주지 않습니다. 내리기는 갱신일에 바뀌도록 예약되고, 갱신일에 잔액이 모자라면 스탠다드로 바뀝니다.

| 모든 등급 공통 | 내용 |
| --- | --- |
| 입금 | 무료. 코인은 받는 즉시 원화 스테이블로 전환 |
| Aqua 회원에게 보내기 | 무료, 바로 처리 |
| 지갑 주소로 보내기 | 네트워크 비용. 원화 스테이블이 아닌 코인으로 보내면 전환 수수료 0.5% |
| 결제 한도 | 최대 1회 50만원·하루 100만원·한 달 500만원, 사용자가 낮출 수 있음 |

원화(법정화폐) 입출금은 지원하지 않습니다. 원화 스테이블의 실제 이름·발행사·네트워크는 제휴 후 정하며 PoC는 `KRWS`라는 자리표시자를 씁니다. 시세는 고정 예시입니다.

KAST는 지원 자산마다 청산 주소를 두고 받은 코인을 거래 확정 즉시 자동 매도해 USD 잔액 하나만 보여 줍니다. Aqua도 코인을 보유하지 않으므로 코인 지갑이나 코인 현황 화면이 없습니다. 실제 전환은 제휴 거래소·OTC가 맡는 구조를 권합니다([KAST 구조의 한국 적용](docs/kast-alignment.md), [공식 조사](docs/kast-funding-model.md), [입출금 흐름](docs/funding-flows.md)).
