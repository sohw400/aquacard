# Aqua Card PoC

한국 사용자를 위한 가상자산 지갑·카드·Reserve·리워드 서비스의 인터랙티브 PoC입니다. React·TypeScript·Vite로 구현하며 모든 자금·카드·거래는 브라우저 안의 데모입니다. 실제 입금, 자산 운용, 카드 신청, 개인정보 확인, 외부 송금이나 과금은 수행하지 않습니다.

## 실행

Node.js 22.12 이상이 필요합니다. 이 환경에서는 24.19.0을 사용합니다.

```bash
cd /workspace/aquacard
npm ci --no-audit --no-fund
npm run dev
```

개발 서버는 5173번 포트를 사용합니다. 의존성 캐시를 쓰기 가능한 위치에 둘 필요가 있으면 `npm_config_cache=/tmp/aquacard-npm-cache`를 사용하세요. 각 클라우드 작업은 격리되어 있으므로 기존 체크아웃을 사용하며 별도 Git worktree를 만들 필요가 없습니다.

## 검증

```bash
npm test
npm run build
```

개발 서버가 실행 중이고 Chromium이 설치된 환경에서는 다음 명령으로 브라우저 흐름을 확인합니다.

```bash
npm run test:browser
npm run test:devices
```

브라우저 검증에 사용할 실행 파일은 `CHROMIUM_PATH`, 서버 주소는 `AQUA_BASE_URL`로 변경할 수 있습니다. 기본 Chromium 경로는 `/usr/bin/chromium`입니다.

2026-10-13 현재 환경에서 재설치·빌드, 금융 상태 로직 22개 테스트, 데스크톱·모바일 브라우저 12개 검증이 통과했습니다. 심사 보완·거절·재신청, 가상·실물 활성화, 잠금, Reserve 결제, 부분·전액 환불, 페이백 조정, 전환·입출금, 실시간 적립·보상률 변경·수령, 상태 복원과 외부 요청이 없음을 확인했습니다. 실제 금융 연동을 검증한 결과는 아닙니다.

브라우저 실행 결과와 화면 이미지는 로컬 `artifacts/`에 생성하며 Git에는 포함하지 않습니다.

현재는 iOS·Android의 화면 크기·터치를 고려한 모바일 웹 PoC입니다. 네이티브 앱 설치 파일은 없습니다. `test:devices`는 320–430px iPhone·Android 5개 프로필을 **Chromium에서 모사**하며 실제 iOS Safari·Android 실기기 검증과 구분합니다. 자세한 실행·수동·실기기 테스트 절차는 [테스트 안내](docs/testing.md)에 있습니다.

## 체험 흐름

공개 웹 배포는 [GitHub Pages 배포 안내](docs/deployment.md)를 따릅니다. 최초 Pages 설정이 필요할 수 있으며, `main` 변경 시 배포 워크플로가 실행됩니다. 배포 주소를 기재한 것만으로 게시 성공을 뜻하지 않습니다.

1. **카드:** 샘플 본인 확인 → 카드 선택 → 신청 → 대행사 모의 심사 → 발급 → 활성화. 심사 보완·거절과 실물 배송·활성화도 체험합니다.
2. **지갑:** 데모 자금 또는 코인 입금 → 코인 전환 견적·수수료 확인 → 결제 잔액 반영. 외부 출금은 모의 잔액 처리입니다.
3. **Reserve:** 자금 이동 → 실시간 보상 표시 → 보상 사용 가능액 반영 → 자유 인출 또는 카드 자동 사용.
4. **결제:** 사용 가능 리워드 → 결제 잔액 → 사용자가 켠 경우 Reserve 부족분 보충. 확정 거래에 페이백을 적립합니다.
5. **이용 내역:** 거래 구성·페이백 확인, 환불과 보상 조정.
6. **설정:** Reserve·리워드 자동 사용, 데모 시간·보상률 변경, 데이터 초기화.

상태는 현재 브라우저의 localStorage에 보존됩니다. 데모 데이터만 사용하며 실제 신분증·주소·계좌·키를 입력하지 마세요. 초기화하면 이 브라우저의 PoC 데이터가 지워집니다.

## 기본 정책

정책의 기준 파일은 [policy.ts](src/lib/policy.ts)입니다.

| 항목 | Basic | Plus |
| --- | --- | --- |
| 이용료 | 무료 | 월 4,900원 안내·실제 과금 없음 |
| Reserve 보상 | 연환산 단리 5%·변동형 | 동일 |
| 보상 대상 Reserve 상한 | 1천만원 | 동일 |
| 카드 페이백 | 1% | 1.5% |
| 월 페이백 상한 | 1만원 | 3만원 |
| 전환비 | 0.5% | 동일 |
| 결제 한도 | 건당 50만원·일 100만원·월 500만원 | 동일 |

원화 충전·내부 자금 이동은 데모 수수료 0원, 최소 1천원입니다. 실물 카드 발급비 9,900원·배송 영업일 5–7일은 계획 값이며 PoC에서 청구·배송하지 않습니다. 시세는 고정 데모 값입니다. 코인 출금의 네트워크 비용은 실제 계산·차감하지 않습니다.

경쟁사 공식 사이트 접근 제한으로 최신 요율을 확인하지 못했습니다. KAST 관련 사용자 관찰과 Aqua의 자체 PoC 정책을 구분했으며 위 수치는 실제 출시 조건이나 약정이 아닙니다.
